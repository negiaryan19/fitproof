# Hackathon notes

Project: FitProof. Track: Commerce & Market Intelligence.

SerpApi is material to the workflow: Google Search discovers device/manufacturer evidence and targeted exact-SKU pages; Google Shopping Light discovers localized offers when the user did not supply a SKU. Search IDs, locale, origin and timestamps are stored. Removing SerpApi removes the live discovery and offer investigation path.

The submitted demo should use one fresh live investigation if the account is configured. A replay can recover from provider outage, but it must be labelled as recorded and cannot be described as current pricing or live retrieval.

AI development/runtime disclosure must contain the actual tools and model used. Deterministic checks remain application code. The team must disclose any pre-existing source, keep secrets out of GitHub, and verify the public repo and under-three-minute video from an incognito window before submission.
